Your new coding bestie, now available in your favourite terminal.

Your tools, your code, and your workflows, wired into your LLM of choice.

Install CrushRead the docs
$git clone https://github.com/brunokrugel/crush.git && cd crush && go install .

The fork isn't packaged anywhere — and go install github.com/charmbracelet/crush@latest gets you upstream, not this. Why.

What's in the box

Everything, wired in

Crush is a terminal-first coding agent built on the Charm stack. Each tile below goes straight to the docs for that feature.

◆

Any model, mid-session

Dozens of providers out of the box, plus anything speaking an OpenAI- or Anthropic-compatible API. Switch LLMs mid-session and keep your context.

Providers & models →⌘

Bash-native config

A crushrc is just Bash with Crush builtins — conditionals, includes, and secrets from your password manager. Identical on Windows.

Configuring Crush →⚙

MCP servers

Extend the agent over stdio, http, and sse, with OAuth 2.1, per-server tool filtering, and MCP prompts and resources in the palette.

MCP →⇄

Channels

MCP servers push real-time events straight into your session — CI failures, webhooks, Signal messages — and Crush acts on them without you typing a thing.

Channels →▣

Multi-agent dispatch

Fan work out to independent agents in their own git worktrees while the main agent keeps going; steer them, read their transcripts, and merge or dismiss their results.

Dispatch →◇

LSP-enhanced

Crush reads your code through language servers, just like you do — diagnostics, definitions, references, call hierarchies, and safe renames.

Language servers →⚑

Skills

The Agent Skills open standard, with four skills built in and discovery from every convention on disk.

Skills →⏱

Scheduled tasks

Give the agent a cron expression and it re-runs a prompt on its own — one-shot reminders or recurring jobs that survive a restart.

Scheduled tasks →⛨

Hooks & permissions

Deterministic control over tool calls: block, rewrite, auto-approve, or inject context before anything runs.

Hooks →⌕

Semantic search

A local vector index over your codebase, so the agent can find code by what it does rather than by what it is called.

Semantic search →⧉

Shared workspaces

Run crush server and point several clients at the same working directory — one session list, history, and permission queue.

Server & workspaces →◐

Cross-session memory

Crush writes each turn to a self-hosted Honcho instance and hands later sessions a picture of how you work — the conventions you settled on, the gotchas you already paid for.

About this build

This is a fork

These docs cover the brunokrugel/crush fork, which tracks charmbracelet/crush upstream and adds a handful of features on top. Where a page documents something the fork adds, it says so — and What this fork adds lists every one of them, along with the things people assume are ours but are actually upstream.

None of it was written in isolation. The fork merges pull requests that are still open upstream, and it carries feature branches picked up from other Crush forks — joestump-agent/crush, taigrr/crush, and gurnben/crush — alongside the work done here. Every addition is credited to where it came from, so nothing is claimed as new that is not.

Crush itself is a Charm project, licensed FSL-1.1-MIT. Bugs in upstream behaviour belong upstream; bugs in the additions below belong to whoever wrote them.

Fork additions

  • Channel reply routing — deterministic replies back through the pushing server
  • Scheduled tasks — cron-driven prompts
  • Cross-session memory — Honcho recall against a self-hosted instance
  • Semantic search — a local vector index over the repo
  • MCP prompts in the / completions and the palette
  • Everything else — click-to-copy, clickable links, a highlighted composer, text attachments, and the Skills, MCP and Channels dialogs

Credits

  • brunokrugel/crush — this fork: the integration work, the snapshots, and the upstream pull requests merged in
  • joestump-agent/crush — multi-agent dispatch, semantic search, channel routing, and most of the TUI polish
  • taigrr/crush — conversation forking and goal mode
  • gurnben/crush — context compaction with checkpoints
