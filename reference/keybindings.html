Keybindings

Press ctrl+g in the app for the live help, which always reflects the running build.

Global​

KeysDoes
ctrl+cQuit
ctrl+gMore help
ctrl+pCommand palette
ctrl+m / ctrl+lModel picker
ctrl+sSession picker
ctrl+zSuspend
tabChange focus
ctrl+yCycle the permission mode: normal → auto mode → yolo
Fork feature

tab is three-state here — chat, editor, sidebar — because the fork makes the sidebar focusable. The command palette groups its system commands into sections (Sessions, Models, Settings, Application), scrolls with the mouse wheel, and a double click runs the command under the pointer.

Editor​

KeysDoes
enterSend
shift+enter / ctrl+jNewline
ctrl+oOpen your $EDITOR for the prompt
@Mention a file, or a live dispatched agent by @handle
/Commands
ctrl+fAdd a file
ctrl+v / super+vPaste an image from the clipboard
ctrl+r then a digitDelete the attachment at that index
ctrl+r rDelete all attachments
escCancel delete mode
↑ / ↓Prompt history

Chat​

KeysDoes
ctrl+nNew session
ctrl+fAdd an attachment
escCancel the running turn
tabChange focus
ctrl+dToggle details
ctrl+tToggle the pills panel (tasks, scheduled tasks)
Fork feature

The scheduled-tasks pill is fork-only, and ctrl+t expands every pills section rather than only the first.

Selection​

KeysDoes
c / yCopy
spaceExpand / collapse the focused item
escClear selection

Finished assistant and user messages also carry a click-to-copy icon, and plain clicks on hyperlinks open them in your browser.

Fork feature

Both the click-to-copy icon and click-to-open hyperlinks are fork additions.

Inspect mode​

Fork feature

Inspect mode is part of multi-agent dispatch. See Handles and inspect.

Read a sub-agent's full transcript — reasoning, tool calls, results — in the chat window while the parent stays the active session. These keys work from both the editor and the chat; an open dialog keeps its own keys.

KeysDoes
ctrl+]On a focused agent block, open that agent's transcript. With no block focused, open the first live agent. While inspecting, cycle to the next live agent
ctrl+[Return to the chat, with the scroll position restored
ctrl+xCancel the selected live dispatch card, or the dispatch you are inspecting. Runs end killed with reason "canceled by user"; the workspace is kept. Shown in the ctrl+g help only while a live dispatch is targeted
escReturn to the chat (same as ctrl+[)
ctrl+] in the session pickerOpen the selected session's sub-agent list. See Sessions

A live agent's transcript follows its stream. Prompts you type while inspecting go to the parent session, never to the agent — to steer a running agent, start the prompt with its @handle. The cycle covers the agents that were live when you entered; agents dispatched later join on your next entry. The drill and back keys appear in the status-bar help and the ctrl+g help whenever they apply: ctrl+] while an agent block is selected, and esc (plus ctrl+] "next agent" when several agents are live) while inspecting.

Initialization prompt​

KeysDoes
yYes
n / escNo
tab / ← / →Switch
enterSelect

Composer completions​

Typing certain characters opens an inline completion list:

TriggerCompletes
@Files in the project, and live dispatched agents by handle, each shown with its role, status, and current todo
/Commands, user-invocable skills, and MCP prompts

A prompt that starts with a live agent's @handle is delivered to that agent instead of the main agent; a @handle later in the prompt attaches the agent's status card. A handle-shaped token (no . or /) that matches a dispatched agent wins over a file of the same name.

Fork feature

Skill, MCP-prompt, and agent completions, @handle routing, the token highlighting that makes them visually distinct, and the atomic-backspace behaviour below are all fork additions. Upstream completes files and commands only.

Completion list size is tunable:

option ui completions-max-depth 4
option ui completions-max-items 200

Backspace over a completed token deletes the whole token — and drops its attachment, if it had one — rather than eating one character at a time.
